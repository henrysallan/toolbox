---
title: Math → JavaScript (scalar mode)
type: math
class: expression
---

- Scalar mode: every operation, with the editor's guards (Divide by 0 → 0,
  Logarithm / Square Root of a non-positive → 0, Arcsine / Arccosine
  clamped, Snap / Wrap / Ping-Pong by 0) and the optional 0–1 clamp.
- **uv** mode is a per-pixel shader (and a wired scalar_field makes a
  field): not a value, so a driver through it is sampled.
