# Text Animators — stackable per-character animation (spec)

Snapshot 2026-06-25. Owner-requested: After-Effects-style **text animators** on
the Text node. A stack of toggleable per-character animations (type-on,
position, opacity, scale, rotation, tracking, color) that are **additive** and
**keyframable** via a single 0–1 Amount each.

## Why it's tractable

The Text node already has the hard part: text-raster.ts's **modulated path**
lays out each glyph individually (per-char advances, glyph centre `(cxCentre,
y)`) and already **samples an image at each glyph's centre** (`sampleMask`) — the
`maskDriven` font-axis mode does `lerp(a, b, fieldSample)` per glyph. Animators
generalize that proven mechanism from font axes to position/opacity/scale/etc.

## Decisions (settled with owner)

- **Driver math:** per glyph, `value = lerp(min, max, t)` where the per-char
  drive `t ∈ [0,1]` is produced from the keyframable **Amount** by the
  animator's **driver mode**:
  - **uniform** → `t = Amount` (same for every char; whole-word animation).
  - **field** → `t = Amount × field(glyphCentre)` — Amount is the master that
    eases the whole effect in; the wired image gives each char its spot in the
    range. No field wired → `field = 1` (falls back to uniform).
  - **cascade** → `t = sweep(Amount, charIndex, total, softness, direction)` —
    characters reach `max` one-by-one as Amount sweeps 0→1 (range-selector /
    type-on).
- **All 7 animators:** Type On, Opacity, Position, Scale, Rotation, Tracking,
  Color. Each has a per-animator driver mode (except Type On = always cascade,
  Tracking = uniform/cascade only — see below).
- **Additive stacking:** offsets sum, scales multiply, rotations sum, alphas
  multiply, tracking sums, color blends. Type On and Opacity are separate
  animators (both fold into glyph alpha) so you can cascade-reveal AND
  field-flicker at once.
- **Primary raster only (v1):** the Auto-Layout `element` output stays plain,
  matching how `maskDriven` is primary-only today (field sampling is in absolute
  canvas coords).

## Per-animator parameters

Generated by a builder in `engine/text-animators.ts` (keeps text.ts lean).
Common: `anim_<P>_enabled` (bool), `anim_<P>_amount` (scalar 0–1, **keyframable**
— this is the thing you animate), `anim_<P>_driver` (enum), cascade-only
`anim_<P>_softness` (0–1 overlap) + `anim_<P>_direction`
(forward/backward/center/edges/random) + `anim_<P>_seed` (for random).
`visibleIf` gates everything on `enabled` (+ driver for the cascade rows).

| P | property params | driver modes | field input |
|---|----------------|--------------|-------------|
| `typeon`   | (fixed 0→1 opacity reveal) | cascade only | — |
| `opacity`  | min/max (0–1) | field/cascade/uniform | `field_opacity` |
| `position` | min/max X, min/max Y (px) | field/cascade/uniform | `field_position` |
| `scale`    | min/max (0–4) | field/cascade/uniform | `field_scale` |
| `rotation` | min/max (deg) | field/cascade/uniform | `field_rotation` |
| `tracking` | min/max (px letter-spacing) | cascade/uniform | — |
| `color`    | min/max (color) | field/cascade/uniform | `field_color` |

**Tracking is index-driven only** (no field): per-char tracking changes glyph
advances → changes centres → would change where a field samples (circular). It's
resolved in the advance pass; the rest resolve in the draw pass at the known
centre.

Field inputs are added by `resolveInputs` only when that animator is enabled and
its driver is `field`, so the node stays clean.

**Collapsible UI.** Each animator's params carry a `ParamDef.group` id (a new,
general ParamPanel hint), and the enable toggle is flagged `groupHeader: true`.
ParamPanel nests grouped params under their header with a collapse **caret** on
the left (default expanded; disabled animators show just the header checkbox,
no caret). Purely a render grouping — collapse state is component-local and
never touches stored params. Generic, so other param-heavy nodes can adopt it.

## Rendering (`engine/text-raster.ts`)

- Force the modulated (per-char) path whenever any animator is active (today
  only varying font axes force it).
- **Advance pass:** add per-char `trackingExtra = lerp(min,max,t)` to the
  advance so alignment/centering stay correct.
- **Draw pass, per glyph:** resolve `GlyphAnim { offsetX, offsetY, scale,
  rotation(rad), alpha, color|null }` from the active animators (field samples
  taken at `(cxCentre, y)`), then draw inside `save()` with
  `globalAlpha *= alpha`, optional `fillStyle = color`, and a transform about
  the glyph centre: `translate(C+offset) · rotate · scale · translate(−C)`.

`engine/text-animators.ts` (new, pure) owns: the param/field-input builders,
`parseAnimators(params)`, `anyAnimatorActive(params)`, the cascade `sweep()`
math, `resolveGlyphAnim(cfg, i, total, fieldSamples)`, and `animatorsSignature`
for the raster cache.

## Wiring (`nodes/source/text.ts`)

- Spread `TEXT_ANIMATOR_PARAMS` into `params`; add `resolveInputs` returning the
  base inputs plus `animatorFieldInputs(params)`.
- Read each wired field image to `ImageData` (generalize `readMaskImageData`);
  build per-field samplers; pass animators + samplers through `renderTextLayer`
  → `drawTextBlock`.
- `modulated = maskMode || anyAnimatorActive(params)` forces the per-char path
  and the per-frame re-raster already used for maskDriven.
- Fold `animatorsSignature(params)` into the raster signature so edits/keyframes
  re-rasterize. Text is already `stable:false`, so keyframed Amounts re-evaluate
  per frame.

## Back-compat

New params/inputs only; no `type`/handle/existing-param changes → existing Text
saves load unchanged (all animators default disabled = today's behavior). No
schema bump.

## Out of scope (v1)

- Animators on the Auto-Layout `element` output.
- Per-word / per-line grouping (character granularity only, per owner).
- Tracking field-driven (index/uniform only). Motion blur. Per-animator easing
  curves on the cascade (softness is the only shaping control for now).
